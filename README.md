# Smart Hackathon Management

## Project Overview

Smart Hackathon Management is a C++ application project designed to simplify and organize the management of hackathon activities. The project aims to provide a centralized platform for managing the different resources and participants involved in a hackathon.

## Project Objectives

- Simplify the organization and management of hackathon activities.
- Facilitate the management of employees, participants, and evaluators.
- Organize rooms and manage their availability.
- Track projects submitted during the hackathon.
- Manage sponsors and their contributions.
- Provide a structured and user-friendly interface.

## Planned Modules

The project is organized around six main modules:

- **Gestion Employés:** Employee and role management.
- **Gestion Salles:** Room management and availability.
- **Gestion Participants:** Participant information and registration management.
- **Gestion Évaluateurs:** Evaluator management.
- **Gestion Projets:** Project management and tracking.
- **Gestion Sponsors:** Sponsor information and contribution management.

## Technologies

- C++
- Qt Framework
- Qt Creator
- Git and GitHub

## Project Organization

The project is developed collaboratively, with each team member contributing to a specific module. Individual modules are developed on separate Git branches before potential integration into the main branch.

The `main` branch serves as the central branch of the repository and is intended to contain the stable version of the project as development progresses.

## Current Status

The project is under development. The modules are being developed separately, and integration will take place progressively as the different components become ready.

## Team Collaboration

Git and GitHub are used to manage source code, track changes, maintain separate development branches, and facilitate collaboration between team members.
